# Архитектура Vocab Deck

Архитектурный проект целевой версии Vocab Deck: серверная часть, база данных, REST API и пользовательская часть. Проект выполнен в рамках практической работы № 3 по дисциплине «Программирование интернет-приложений» и опирается на техническое задание из практической работы № 2.

Текущая версия в репозитории — кликабельный прототип на чистом JavaScript. Документы ниже описывают, как приложение будет устроено после перехода на клиент-серверную архитектуру.

## Кратко

| Часть | Решение |
|---|---|
| Архитектура | Трёхуровневая: SPA в браузере → REST API → PostgreSQL |
| Сервер | Python, FastAPI, модульный монолит из 8 модулей (`auth`, `users`, `decks`, `words`, `learning`, `gamification`, `admin`, `core`) |
| База данных | PostgreSQL, 9 таблиц, третья нормальная форма |
| API | REST, `/api/v1`, 32 эндпоинта, единый формат ответов и ошибок |
| Клиент | React + TypeScript, паттерн Flux (Redux Toolkit), структура Feature-Sliced Design |
| Безопасность | Опыт и прогресс считает только сервер; сессия в HttpOnly-cookie; гостевой прогресс защищён подписанными квитанциями |
