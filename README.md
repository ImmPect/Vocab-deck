# Vocab Deck 🃏

Интерактивные флеш-карточки для изучения английской лексики (уровень A2→B1), сделанные в стиле бумажных карточек-каталога.

**🔗 Демо:** https://ImmPect.github.io/Vocab-deck/

## Идея

Пользователь листает карточки со словами и сам решает, что уже знает, а что нужно повторить:

- клик по карточке — переворот и показ перевода + примера предложения
- **📥 Отложить учить** — слово уходит в корзину для повторения
- **✅ Знаю** — слово помечается как выученное
- прогресс сохраняется в браузере (`localStorage`) и не пропадает при перезагрузке
- по завершении колоды можно отдельно повторить только слова из корзины «учить»

## Архитектура

Архитектурный проект целевой версии (сервер на FastAPI, PostgreSQL, React-клиент, REST API, диаграммы C4, ER и UML) — в папке [docs/architecture](docs/architecture/README.md).

## Серверная часть

REST API на FastAPI + SQLAlchemy + Alembic (PostgreSQL / SQLite) — в папке [backend](backend/README.md): 32 эндпоинта, 134 автотеста, 175 слов в 7 отделах, документация Swagger UI по адресу `/docs`.

## Клиентская часть

SPA на React + TypeScript + Vite, Redux Toolkit (паттерн Flux) и RTK Query, структура Feature-Sliced Design — в папке [frontend](frontend/README.md): 11 экранов, гостевой режим с переносом прогресса, офлайн-очередь ответов, адаптивная вёрстка от 360 px.

## Стек

Чистый HTML / CSS / JavaScript, без фреймворков и зависимостей — один файл `index.html`, который можно открыть где угодно.

## Как запустить локально

Просто открыть `index.html` в браузере — сборка не требуется.
